# Orçamentos

Sistema web de orçamentos para pequenas empresas (oficinas, gráficas, marcenarias):
monta o orçamento, manda pelo WhatsApp, sabe se o cliente viu e lembra de cobrar.

- **No ar:** https://orcamentos-psi-lilac.vercel.app
- **Tecnologias:** Next.js (App Router) + TypeScript, Tailwind CSS, Prisma + PostgreSQL (Neon), Vercel.

**Comece pelo [`MAPA.md`](MAPA.md):** ele explica como rodar, as regras que não podem ser
quebradas, como os dados andam e o que faz cada arquivo.

```bash
npm install        # instala tudo
npm run dev        # liga o sistema em http://localhost:3000
```
